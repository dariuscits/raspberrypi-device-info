# Raspberry Pi Device Info

A simple Bash script that displays the Raspberry Pi's hostname and MAC address.

## Output

Example:

```text
Device: raspberrypi MAC Address: dc:a6:32:ab:12:34
```

## Requirements

- Raspberry Pi OS
- Bash

## Installation

Clone the repository:

```bash
git clone https://github.com/dariuscits/raspberrypi-device-info.git
```

Move into the directory:

```bash
cd raspberrypi-device-info
```

Make the script executable:

```bash
chmod +x device_info.sh
```

Run the script:

```bash
./device_info.sh
```

## Example Output

```text
Device: raspberrypi MAC Address: dc:a6:32:ab:12:34
```
